# Multi-company question bank — ingested-corpus evaluation sessions

Six mock analyst sessions, 36 chained turns, built from the full ingested
corpus rather than the LITE pilot alone. The questions are intentionally
cross-file and cross-company: follow-ups should carry forward the prior
company, metric, date, and scenario instead of answering each turn as a new
single-shot lookup.

Source dates differ substantially. A correct answer should identify the source
date when estimates conflict and should not silently merge an older cycle view
with a newer forecast.
